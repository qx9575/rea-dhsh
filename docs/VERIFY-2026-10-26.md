## 3. 审计发现：APCI 12B `+6` 文档错误（已修正）

`docs/formats/apci.md` §3/§5 与 `apci-12b-units.json` 原表述：
“`+0x06` 在该路径未被读取；时序值来自 `+0x0a`（经临时结构 +6/+8）”。

**复核结果：不成立。** `FUN_0043f380` 反编译：

```
timing[i] = *(u16*)(units + i*0xc + 6) * 10;   // 写入 param_1[0x45]
```

- 主路径单元由 `FUN_00827be0` **逐字拷贝**（3 dwords），`+6` = 槽位 3；
- 旧表述混淆了 fallback 重建分支（缺单元时 `dst+6 = src+10`）；
- 按已证布局 `[f0,f1,f4,f5,f2,f3]`，槽位 3 = **PIF `f5` 帧延时**，
  其 top 值 80/100/120/140 与 PIF 延时分布一致；
- 由此 `+6`/PIF 延时对应关系**闭合**（原 PROGRESS 待定项移除）。

已更新：`docs/formats/apci.md`、`docs/PROGRESS.md`、
`manifests/batches/apci-12b-units.json`（保留修正说明）。
