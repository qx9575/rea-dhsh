## 2. 工具与常用命令

```bash
# 全量校验
python tools/paperdoll/cli.py validate --shdata D:/software/dhsh2/shdata \
  --action 10 --direction 0 --out extracted/paperdoll

# 单预设清单/渲染
python tools/paperdoll/cli.py manifest --shdata D:/software/dhsh2/shdata \
  --career 4 --advance 0 --mount-tier 0 --gender 1 --action 10 --direction 0 \
  --out extracted/paperdoll

# 术士女 + 灵兽套 + 桃木杖
python tools/paperdoll/cli.py render --shdata D:/software/dhsh2/shdata \
  --career 4 --advance 0 --mount-tier 0 --gender 1 --head 450 \
  --actions 10 --directions 2 \
  --equip 1400 --equip 2450 --equip 8400 --equip 9450 \
  --equip 11450 --equip 4400 --out extracted/paperdoll/equip

# 只读运行时路径快照/差分
python tools/runtime_path_snapshot.py --pid <PID> --out paths-before.json
python tools/runtime_path_snapshot.py --pid <PID> --out paths-after.json
python tools/runtime_path_snapshot.py --diff paths-before.json paths-after.json
```

主要 CLI 旗标：

```text
--override PART=MODEL     直接覆盖部件
--equip ITEM_ID           按物品槽位/实测表覆盖
--star-general ID         星将形态行（bodyidequal 36xxx/38xxx）
--star-auto               按职业/性别取默认星将行
--head-hue DEG            头部/发型色相
--mount-model MODEL       直接坐骑资源模型
--mount-id ID             horseinfo 坐骑元数据
--mount-form ride|god     ride=骑乘；god=神骑/骑甲一体
--wing ID                 faeriewing 翅膀 ID
--pet ID / --pet-action / --pet-frame
--summon SHAPE / --summon-name NAME
--skill ID / --skill-effect ID / --skill-variant / --skill-layer
```
