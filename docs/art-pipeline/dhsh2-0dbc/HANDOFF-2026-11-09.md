## 4. 运行时内存扫描方法

- `Game.exe` 是 32 位进程；Python ctypes：
  `OpenProcess(PROCESS_QUERY_INFORMATION|PROCESS_VM_READ, 0x0410)` →
  `VirtualQueryEx` 遍历可读区域 → `ReadProcessMemory` 分块搜索。
- 锚点：角色名（ASCII/UTF-16/GBK）、角色 ID、属性值（HP/MP/等级）、物品 ID、
  客户端缓存资源路径（如 `player\cloth/453/30/4`）。
- 已验证可定位属性结构与装备资源路径。**进程重启后 PID/地址全部失效，需重扫**。
- 保护组件存在，但只读访问未被阻止；不要注入或写内存。
