# DHSH 职业 / 装备 / 技能 / 坐骑 / 召唤兽关系

> 2026-11-10 整理。此文档只记录数据表与运行时观察到的关系，**不修改 paperdoll 渲染代码**。
> 目标是先把“职业限定”这一层理清，再回到装备外观映射。

## 0. 一句话结论

外观解析必须带职业维度：

```text
(career, advance, gender, mount_tier, transform_id, item_id) → (part, model, hue)
```

只按 `item_id` 或数值接近去猜模型会持续出错。模型 ID 本身通常带**职业族前缀**；
物品、坐骑、技能都有职业限定；**变身会隐藏装备，坐骑不会**（2026-11-10 用户实测）。

## 1. 实体关系图

```text
职业 career (0–16)
 ├─ 进阶 advance: 0 职业 / 1 英雄 / 2 星将
 ├─ 性别 gender: 0 男 / 1 女
 ├─ 基础外观 viewjob: body/head 默认 + cloth/glove/shoe/weapon 资源 ID
 ├─ 坐骑等级 mount_tier: 0 徒步 / 1 坐骑 / 2 神骑
 │    └─ 坐骑 ID、骑甲头/身 ID → horse/harmor 模型
 ├─ 技能 Skill.csv: 职业列 + 攻击/受击/失败光效 → magic*.pak
 ├─ 变身/星神: 覆盖外观；装备隐藏
 │    └─ 星神幻化造型 ID（viewjob 最后一列）
 └─ 装备权限 itemSpecData: 每个职业列 0/1

物品 item
 ├─ 物品 ID / 图标 ID / 名称
 ├─ 槽位 slot（物品位置，第 30 列）
 ├─ 职业权限（第 3–19 列）
 └─ 外观模型（需按职业族过滤）
      ├─ 低阶：item_id 尾数与槽位偏移
      └─ 高阶：套装/职业族/客户端外观 ID，尚未闭合

坐骑 mount
 ├─ horseinfo: 坐骑 ID、怪物 ID、最佳职业、等级、飞行、类型、品级
 ├─ viewjob: 坐骑等级 + 坐骑资源 ID + 骑甲头/身 ID
 └─ horseoffset: 人物/坐骑/宠物/翅膀/披风等偏移

召唤兽/宠物 summon/pet
 ├─ monsters.csv: shape → 模型
 ├─ petinfo / pet_skill: 名称/技能
 └─ petequipsetname: 宠物装备套装（独立模型空间）
```

## 3. 物品与外观

### 3.1 `itemSpecData.csv`（`ui.pak:item/itemSpecData.csv`）

关键列：

| 列 | 含义 |
|---:|---|
| 0 | 物品 ID |
| 1 | 图标 ID（`ui.pak:icon/big/<5位>.a16`） |
| 2 | 名称（常带 `（剑）/（武）/（浪）/（卫）…` 职业后缀） |
| 3–19 | 职业权限：初心者/剑客/武师/医师/术士/道士/刺客/猎人/禁卫/墨者/巫煞/魂武/寒星/花间舞/剑九/魔刀/百变，1 可用 |
| 20 | 使用阶段（0 所有/1 入职/2 英雄/3 星将/4 星神/5 星魔） |
| 21 | 可使用等级 |
| 30 | 物品位置（槽位） |
| 31 | 使用类型 |

### 3.2 槽位 → 部件目录（paperdoll 已用）

| slot | 部件 |
|---:|---|
| 10 | head |
| 20 | cloth |
| 30 | 背饰/披风（未解析，可能走 effect/cloak） |
| 40 | weapon |
| 80 | mask（腰带按当前约定） |
| 90 | shoe |
| 100 | mask（面罩） |
| 110 | lcuff / rcuff |
| 270 | harmorbody（骑甲） |

### 3.3 低阶物品的模型公式（已实测）

```text
weapon      : item_id % 1000 + 50   （4400→450，4402→452）
cloth/shoe/cuff: item_id % 1000 + 3 （2450→453，9450→453，11450→453）
mask/belt   : item_id % 1000 + 50   （8400→450）
head        : 推测 +50，待验证
```

该公式只对低阶/同族物品成立；高阶套装（如神佑、诸侯黄昏）不适用，
必须结合**职业族 + 套装/图标/客户端外观 ID**。`bodyidequal.csv` 是怪物/对等身体外观，
不是玩家物品表。

### 3.4 其他外观相关表

| 表 | 作用 |
|---|---|
| `config.pak:bodyidequal.csv` | 对等身体 ID → 头/衣/武器/光效/鞋/面具/护腕 ID + 颜色；用于怪物/NPC |
| `config.pak:misc/resmirror.csv` | 部件类型 + 部件ID + 动作 + 朝向 → 替换模型（不是朝向镜像） |
| `config.pak:ui/user/shapeclrinfo.csv` | 部件类型 + 部件ID → 颜色参数（0–251） |
| `config.pak:misc/colorconvert.csv` | 坐骑（13）颜色 → 新颜色/部件信息 |
| `config.pak:cloakoffset.csv` | 披风 ID + 人物/坐骑 ID → 偏移 |

## 4. 坐骑

`horseinfo.csv` 字段：

```text
坐骑ID, 怪物ID, 坐骑等级(1–3), 最佳职业, 需要坐骑技能, 坐骑名称/说明,
是否飞行, 是否元宝, 坐骑类型, 坐骑品级, 坐骑特技, 获得途径,
图鉴排序, 变色升级坐骑ID, 性别, 星座, 样貌, 性格, 原种族, 是否可激活
```

`viewjob.csv` 中坐骑列：

- `mount_tier`: 0 徒步 / 1 坐骑 / 2 神骑
- `mount_id`、`harmor_head_id`、`harmor_body_id`
- 神骑时 `mount_id` 与骑甲 ID 常相同（如 7600/7650），对应 `horse/harmorbody/harmorhead` 同模型。

`horseoffset.csv` 给出人物/坐骑/宠物/翅膀/披风/星将光效/头部/脚底光环/中心特效偏移；
它只影响叠放，不决定模型 ID。

### 4.1 当前观察（2026-11-10）

- `player6/horse/6100` 渲染为红色火龙，当前 159 角色骑乘的**赤炎龙**候选；
- `player11/horse/14650` 渲染为蓝白冰龙，当前 139 圣手的**冰龙**候选；
- `player6/horse/6150` 也是红色火龙变体，需与 6100 区分；
- 之前记录的 6000 冰龙/6150 赤焰龙需要在职业/坐骑维度下重新确认。
- **用户实测：坐骑状态不隐藏装备；变身状态隐藏装备。**

坐骑也有职业限制（`horseinfo.最佳职业`、坐骑等级/类型），解析时不要把坐骑 ID 当唯一键。

## 5. 技能与光效

`Skill.csv` 关键列：

```text
技能标识, 技能名称, 技能描述, 技能所属职业, 技能所属系, 阶位, 图标,
目标个数, 受击光效, 攻击光效, 失败光效, 是否前冲, 是否敌人,
伤害值1–8, 攻击帧1–8, SP/金钱/技能点, 技能界面坐标,
前置技能ID, 背景色彩, 透明度, 光效方向标志, 是否全屏魔法,
声音配置, 是否多体魔法, 攻击动作, 攻击距离, 技能系别, 是否主动技能, ...
```

光效 ID（受击/攻击/失败）指向 `magic*.pak:<model>/<variant>/front|back.apg`；
技能职业列决定哪些职业可用，不能跨职业套用光效。

## 6. 召唤兽 / 宠物

- `monsters.csv`: `shape` → 怪物/召唤兽模型；`下一阶 shapeID` 用于进化。
- `petinfo.csv` / `pet_skill.csv`: 宠物名称与技能。
- 宠物外观在 `pet/<id>/<action>/<dir>.apg`，与玩家部件空间独立。
- `petequipsetname.csv` / `summoner_equip_recipe.csv`: 宠物装备套装与打造。
- 宠物/召唤兽不参与玩家 `item_id → 部件模型` 映射，需要单独解析。

## 7. 变身 / 星神

- `item_spec.csv` 中 `道具分类 9 = 变身`，例如：
  - `59344 潜影变身符（男）`
  - `59358 潜影变身符（女）`
- `viewjob.csv` 最后一列 `星神幻化造型ID`（如剑客 27090、浪子 27110）。
- 变身/星神状态会**覆盖外观并隐藏装备**（用户实测）；因此不能在这种状态下读取装备模型。
- **潜影**：用户确认该角色是“浪子转出来的”，且当前不是星神变身状态，装备可见。
  `潜影` 未出现在 `viewjob` 职业名中，需在星将/英雄名表或技能表中继续定位；
  但外观族应先按 **职业 6 浪子 = 6xx** 处理，而不是 66xx（寒星）。

## 8. 待解决

1. **职业族过滤**：paperdoll 的外观表要从 `item_id` 改为
   `(item_id, career, advance, gender, transform_id)`。
2. **高阶套装映射**：低阶公式之外，需要建立“套装/图标 → 职业族内模型”的表；
   先用 `viewjob` 基础 ID 限定族，再在族内找套装模型。
3. **159 潜影实际外观**：已定位 `bodyidequal 36615`（浪子星将·女）：
   `body 650 / head 662 / cloth 671 / weapon 671 / shoe 671 / cuff 671`。
   神佑血匕/仙袍/仙靴/仙腕已由用户目视确认；`head/662` 当前 PAK 缺失，
   神佑神带（mask）不可见。
4. **坐骑职业限制**：`horseinfo.最佳职业`、`viewjob` 坐骑等级/神骑骑甲要进入解析器。
5. **技能/光效**：按 Skill.csv 职业列过滤，避免跨职业光效。
6. **宠物/召唤兽**：独立模型空间，单独建索引。
7. **变身状态**：解析器需要 `transform_id`，命中时跳过装备外观。
