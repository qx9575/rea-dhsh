# 点击光圈 x32dbg 定点分析设计

## 目标与边界

定位左键点击可走地面后蓝白椭圆环的原版触发/绘制路径。旧基线继续只读；新版只使用 x32dbg 的单次条件断点。暂停 Frida 热路径挂钩、内存页监听、Lua 注入和通用 DLL 挂钩，不修改游戏磁盘文件。

## 方案

1. 用旧版 `0x416770` 的掩码字节签名映射新版主窗口消息分发函数 `0x4168d0`。
2. 使用 x32dbg 官方 `-p PID` 附加进程，并通过 `-cf` 执行脚本。
3. 在 `0x4168d0` 设置条件 `[esp+4]==0x201`，仅捕获 `WM_LBUTTONDOWN`。
4. 命中后记录寄存器、消息参数和 `printstack` 调用栈；清除断点并执行 `detach`，让游戏继续。
5. 通过 x32dbg 日志/窗口读取结果。若入口未命中，不重复点击，重新核对版本映射。

## 安全与验证

- 调试器通过分离进程启动，不受 Bash 任务超时影响。
- 脚本只安装一个低频条件断点，不做全量 Trace。
- 脚本必须在退出前清除断点并脱离；运行后核对游戏和 x32dbg 进程状态。
- 单次命中只证明消息入口，不直接证明光圈路径；后续定点分析需以调用栈和旧基线静态证据交叉验证。
