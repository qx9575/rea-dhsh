# Native Client Task 12：本地角色与 NPC 预设

Task 12 只实现本地实体、动画和场景合成，不包含网络、战斗、NPC 对话或 A* 寻路；点击寻路由 Task 13 实现。

## 角色出生点

应天府使用 `map/YingTianFu.mlk` 中 `target=YTF_YaMen.map` 的记录。该记录的 `dest=(6960,2128)` 是格 `(435,133)` 的左上角，因此角色逻辑位置为格中心 `(6968,2136)`；`extra0=1` 映射为左下。此映射与 `docs/formats/map.md` 第 5 节的运行时证据一致。

真实 CEL 地面层检查确认格 `(435,133)` 可走。角色继续使用 Task 11 的显式真实预设 `player.pak:body/200 + head/105`，动作 `10=Idle`、`30=Walk`。640×480 合成画布的锚点是 `(320,240)`，所以绘制原点为角色逻辑位置减去该锚点。

## 显式 M1 本地 NPC 预设

NPC 放置数据尚未用于本客户端，不猜测原配置语义。Task 12 明确采用以下**本地展示预设**，它不是对原应天府 NPC 放置表的还原：

- 资源：`npc.pak:10009/10/3.apg`；
- 动作/方向：Idle，右下（资源方向 `3`）；
- 逻辑位置：`(7000,2152)`，即格 `(437,134)` 的中心；
- 真实 CEL 地面层检查：该格可走；
- 绘制原点：实体逻辑位置加当前 APG 帧的 `anchor_x/anchor_y`，不使用画布中心假设。

NPC 仅推进本地 `AnimationClip`，不会移动、切换 Walk、联网或触发战斗。单个 NPC 资源加载失败时记录逻辑路径并跳过；角色核心资源失败仍停止进入场景。
